# Super Sales Power BI Report

A Power BI project by Reem Ashraf covering sales performance, profitability, and monthly reporting.

- **Overview** summarizes sales performance with cards, charts, and filters.
- **Profit Dashboard** explores profitability across categories and on a map.
- **Dashboard** and **Report Monthly** provide trend charts and tabular views for further analysis.

[Download the Power BI file](Reem%20Ashraf%20%20super%20sales.pbix) and open it in Power BI Desktop.
