# Super Sales | Power BI Dashboard

Power BI project by **Reem Ashraf** exploring sales, profitability, and monthly performance using a sample retail dataset.

## Report pages

| Page | What to explore |
| --- | --- |
| Overview | Sales KPIs, geographic views, and interactive filters |
| Profit Dashboard | Profitability comparisons, trends, and geographic patterns |
| Dashboard | Performance trends and detailed tables |
| Report Monthly | Monthly summaries and comparisons |

## Files

| File | Contents |
| --- | --- |
| [Power BI report](Reem%20Ashraf%20%20super%20sales.pbix) | Interactive report for Power BI Desktop |
| [Excel dataset](Lecture%2010%20super%20sales.xlsx) | The source workbook with Orders, Returns, and People worksheets |

**Orders** contains order and shipping dates, customer segments, geography, product categories, and sales, quantity, discount, and profit fields. **Returns** lists returned order IDs. **People** maps people to regions.

## Open and refresh

1. Download both files and open the PBIX in Power BI Desktop.
2. If refresh cannot find the workbook, open **File → Options and settings → Data source settings**, select the Excel source, and point it to the downloaded workbook.
3. Refresh the report and use the page navigation and filters to explore the data.
